# Gardenia convention center website - including admin panel

Gardenia convention center website is a small Full stack application designed and built with both admin and client side interface.

- Client Side Interface : Showcases the center's stage details, features, highlights and contact enquiry section for user to reach out to the administration member.
- Admin Side Interface : A secure panel for administrative members who can handle both events and job openings related to the convention center.

## Table of content

- [Features](#features)

# Features

- Secure Authentication using JWT + Http Only Cookies and Role based admin page access
- Admin can add or manage or mark events on calendar.
- Admin can also handle job openings within the convention center.
- Client side interface is given with google map for easy tracking of location with enquiry form to submit enquiry.

---

# Tech Stack

- **Frontend:** ReacJS + Vite, TailwindCSS.
- **Backend:** NodeJS and ExpressJS.
- **Database:** MongoDB.
- **Authentication:** JWT (JSON Web Token)
